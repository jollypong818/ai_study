# AI 엔지니어 전환 스터디 저장소 (Spring 3년 차 ver.)

Java/Spring 백엔드 개발 감각으로 머신러닝·AI를 주제별로 실습하고, 30분 공유 발표까지 연결하는 스터디 공간입니다.  
모든 실습 노트북은 **Google Colab**에서 별도 설치 없이 바로 실행됩니다.

| :--- | :--- | :--- | :--- | :---: |
| **회귀 (Regression)** | [regression](./regression/README.md) | UCI Bike Sharing (`dataset/hour.csv`) | MAE (평균 오차 대수) | Step 1~5 + 30분 대본 완료 |

## 새 주제(데이터셋) 학습자료 자동 생성하기

이 저장소에는 [`ml-study-course-builder`](./.agents/skills/ml-study-course-builder/SKILL.md) 스킬이 등록되어 있습니다.  
앞으로 새 주제를 공부하고 싶을 때는 **데이터셋 링크(또는 CSV 파일)와 주제만 알려주면** 아래 구조로 하위폴더와 전체 자료가 자동 생성됩니다.

> **사용 예시:**
> - *"이번엔 분류 공부할 건데 https://... 이 데이터셋으로 학습자료 만들어줘"*
> - *"타이타닉 데이터로 분류 실습 폴더 만들어줘"*
> - *"이 CSV 파일로 시계열 예측 스터디 자료 만들어줘"*

자동으로 지켜지는 기준:
- **폴더 규칙:** `regression/`, `classification/`, `clustering/`, `timeseries/` 등 주제별 하위폴더와 `dataset/` 폴더 생성 *(같은 주제의 두 번째 데이터셋은 `regression_<데이터셋명>/` 사용)*
- **교수법:** Spring↔ML 매핑 + `[실행 전 예측]` 질문 + 실전 함정 3개 직접 터뜨리기 + 1단계=1변경=1수치
- **코드 해설:** 모든 코드 셀마다 파이썬 문법 + Java/SQL 비유로 상세 해설 포함
- **발표 자료:** 4시간 자습 분량을 30분 구어체 발표 대본(`PRESENTATION_30MIN.md`)으로 압축
- **문체:** AI 특유의 추상적·방어적 말투 금지
