## 1. 이 과정의 3가지 설계 원칙

1. **Spring 감각에 바로 연결한다**
   | ML 용어 | 백엔드 개발자 번역 |
   | :--- | :--- |
   | 모델 학습 | `if-else` 규칙을 사람이 안 짜고, 과거 데이터로 규칙 함수를 자동 생성 |
   | EDA (탐색적 분석) | 코드 짜기 전에 `SELECT * LIMIT 10`으로 DB 테이블과 이상 데이터부터 확인 |
   | 데이터 누수 (Leakage) | 테스트 코드에 정답을 미리 박아두고 단위 테스트 통과했다고 착각하는 버그 |
   | Train / Test 분리 | 로컬에서만 돌려보고 운영(Prod) 트래픽 검증 없이 배포하는 걸 막는 분리 |
   | 피처 엔지니어링 | Raw DB 컬럼을 모델이 잘 읽도록 가공하는 DTO / 쿼리 프로젝션 |
   | 평가지표 (MAE) | API p95 응답시간 같은 벤치마크 수치. "평균 몇 대 틀렸는지" 숫자로 비교 |

2. **정답 전에 '버그'부터 일부러 터뜨린다 (생산적 실패)**
   - **함정 1:** `casual + registered = cnt`를 모르고 넣어서 오차 `0.00대`짜리 가짜 모델 만들기
   - **함정 2:** 시간 데이터를 랜덤으로 섞어 미래를 컨닝하는 테스트(`24.90대` 착시) 만들기
   - **함정 3:** 직선 모델(선형회귀, `136.23대`)로 출퇴근 쌍봉 그래프를 맞추려다 망해보기

3. **1단계 = 1변경 = 1수치**
   - 매 단계마다 딱 하나만 바꾸고 오차(MAE: 평균 몇 대 틀리는지)가 어떻게 변했는지 기록합니다.

## 3. 실험 벤치마크 기록표 (실제 `hour.csv` 검증 수치)

| 실험 번호 | 변경한 것 (딱 1개) | 평가 방식 | Test MAE (평균 오차 대수) | 핵심 배운 점 |
| :---: | :--- | :--- | :---: | :--- |
| **Exp 0** | 무조건 학습 평균값 찍기 (Baseline) | 시계열 분할 (`2012-09-01`) | **170.51대** | 아무것도 안 배운 바닥 기준선 |
| **Exp 1** | 모든 컬럼 그대로 투입 (**함정 1**) | 랜덤 분할 | **0.00대** *(가짜)* | `casual+registered` 데이터 누수 버그 |
| **Exp 2** | 누수 제거 + RandomForest (**함정 2**) | 랜덤 분할 | **24.90대** *(가짜)* | 10시·12시 보고 11시 맞추는 미래 컨닝 |
| **Exp 3** | 분할 방식만 시계열로 교정 + 선형회귀 (**함정 3**) | 시계열 분할 | **136.23대** | 직선으로는 출퇴근 쌍봉 그래프 못 그림 |
| **Exp 4a** | 모델만 결정트리(DecisionTree)로 교체 | 시계열 분할 | **58.96대** | `Train 0.01 vs Test 58.96` 과적합 체감 |
| **Exp 4b** | 모델만 RandomForest로 교체 | 시계열 분할 | **47.48대** | 100그루 평균으로 과적합 완화 + 에러 분석 |
| **Exp 5a** | 모델만 Gradient Boosting으로 교체 | 시계열 분할 | **45.11대** | 오차를 순차 보완하는 부스팅 효과 |
| **Exp 5b** | DB 과거 이력 피처 3개 추가 (1d/7d/14d) | 시계열 분할 | **43.62대** | **최종 모델! 기준선 대비 오차 74% 감소** |
